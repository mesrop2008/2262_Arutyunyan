#### Объяснение работы строк программы

1. Строка print(l, d):
   В функцию передаются два позиционных аргумента: список l и словарь d. По умолчанию разделителем аргументов в функции print является пробел, а завершением — символ перевода строки. Функция выводит строковое представление списка и словаря через пробел.

2. Строка print(*l, d):
   Оператор распаковки с одной звездочкой *l раскладывает список на отдельные элементы. В функцию передаются четыре позиционных аргумента из списка и пятый аргумент — словарь d. Все пять аргументов выводятся через пробел.

3. Строка print(*l, *d):
   Список l распаковывается на четыре элемента. Словарь d с одной звездочкой распаковывает свои ключи: строки sep и end. В функцию передаются шесть позиционных аргументов, которые выводятся через пробел.

4. Строка print(*l, **d):
   Оператор с двумя звездочками **d распаковывает словарь в именованные аргументы вызова функции. Это эквивалентно вызову print(*l, sep=',', end='\n'). Встроенная функция print принимает параметр sep как разделитель между элементами, а end как завершающий символ. В результате элементы списка выводятся через запятую.


### Задание 2 **(2)**
*Напишите функцию sublist для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций. Функция должна составить и вернуть список из элементов, которые находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*
```python
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

#### Решение

Файл с программой: [02/main.py](02/main.py).

```python
def sublist(seq, *indices):
    return [seq[i] for i in indices]
```

#### Объяснение работы функции

Параметр *indices принимает произвольное количество позиционных аргументов и упаковывает их в кортеж. Если номера позиций не переданы, кортеж indices оказывается пустым, и генератор возвращает пустой список [].

При передаче номеров позиций генератор списка последовательно извлекает элементы seq[i] для каждого индекса i из кортежа indices и формирует новый результирующий список. Функция корректно работает как со списками, так и с кортежами.

*Запишите фрагмент программы, которая упорядочит список слов по длине, а при равенстве длины - лексикографически. Сортировка должна состоять из одного вызова метода sort.*

*Пример работы приводится ниже.*
```python
>>> lst = ['hello', 'hell', 'bye', 'world', 'bybye']
>>> lst.sort (...)
>>> print (lst)
['bye', 'hell', 'babye', 'hello', 'world']
```

#### Решение

Файл с программой: [04/main.py](04/main.py).

Фрагмент программы:
```python
lst.sort(key=lambda s: (len(s), s))
```

#### Объяснение

Метод sort принимает параметр key. Лямбда-функция возвращает для каждого слова кортеж из двух значений: длину слова len(s) и само слово s.

В Python кортежи сравниваются поэлементно: сначала сравнивается первый элемент (длина). Если длины слов совпадают, то сравнивается второй элемент (само слово по алфавиту). Таким образом, список упорядочивается сначала по возрастанию длины, а слова одинаковой длины сортируются лексикографически.

### Задание 6 **(2)**
*Запишите генератор в форме функции, который будет создавать последовательность по следующему правилу.*

*Если текущее число x в последовательности четное, то следующее число равно x/2.*
*Иначе следующее число равно 3x + 1.*
*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```python
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

#### Решение

Файл с программой: [06/main.py](06/main.py).

```python
def gen(n):
    yield n
    while n != 1:
        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1
        yield n
```

#### Объяснение

Генератор сначала выдает исходное число n с помощью инструкции yield. Далее в цикле while проверяется, не достигло ли число единицы. Если текущее число четное, оно делится нацело на 2. Если нечетное — умножается на 3 и увеличивается на 1. Новое значение передается наружу через yield. Когда значение становится равным 1, цикл завершается.

### Задание 7 **(2)**
*Напишите генератор, который для заданной последовательности seq будет задавать последовательность из каждого второго элемента seq.*
```python
def every_other ( seq ):
    ...
```
*Ниже приведены примеры использования генератра.*
```python
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

#### Решение

Файл с программой: [07/main.py](07/main.py).

```python
def every_other(seq):
    flag = True
    for item in seq:
        if flag:
            yield item
        flag = not flag
```

#### Объяснение

Входной параметр seq может быть не только списком, но и генератором, объектом map или однократным итератором, для которых недоступно обращение по индексу или срезы. Поэтому функция обходит переданную последовательность через цикл for.

Логическая переменная flag служит переключателем. На первом элементе flag равен True, и значение выдается через yield. Затем флаг меняется на противоположный, следующий элемент пропускается, и флаг снова становится True. Таким образом возвращается каждый второй элемент последовательности (с четными порядковыми номерами 0, 2, 4 и так далее).

*Какие из указанных функций и методов Python соответствуют определению чистых функций? В случае отрицательного ответа требуется дать пояснение.*

#### Решение

Файл с программой: [10/main.py](10/main.py).

Чистая функция — это функция, результат работы которой зависит только от переданных ей входных аргументов, и выполнение которой не вызывает побочных эффектов (не изменяет состояние программы, не модифицирует переданные аргументы и не выполняет операций ввода-вывода).

#### Анализ функций и методов

1. file.readline:
   Не является чистой функцией. Метод изменяет внутреннее состояние файлового объекта (смещает указатель текущей позиции чтения в файле). Кроме того, при повторном вызове с теми же аргументами возвращается уже другая строка файла.

2. len:
   Чистая функция. Возвращает длину переданного контейнера, не изменяя его состояние и не производя побочных эффектов.

3. list.append:
   Не является чистой функцией. Метод имеет побочный эффект: он мутирует переданный список на месте, изменяя его длину и состав, а сам возвращает None.

4. sum:
   Чистая функция. Вычисляет сумму элементов переданной последовательности, не модифицируя саму последовательность.

5. sorted:
   Чистая функция. Принимает последовательность и возвращает новый отсортированный список, при этом исходная последовательность остается неизменной.

6. list.sort:
   Не является чистой функцией. Метод сортирует список на месте, перезаписывая его внутреннее состояние.

7. random.randint:
   Не является чистой функцией. Она недетерминирована (при одинаковых аргументах выдает разные случайные числа) и изменяет внутреннее состояние генератора псевдослучайных чисел.

8. Функция rev(x):
   Чистая функция. Срез x[::-1] создает и возвращает новый объект с элементами в обратном порядке. Исходный объект x не модифицируется.

9. Функция tail(x):
   Не является чистой функцией. Функция зависит от внешнего глобального состояния — переменной tail_len, которая не передана в качестве аргумента. Если значение tail_len изменится в другой части программы, функция при том же аргументе x вернет другой результат.

### Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию toint? Что возвращает эта функция? Что делает функция wrapper? Придумайте несколько примеров использования toint.*

#### Решение

Файл с программой: [11/main.py](11/main.py).

#### Ответы на вопросы

1. Что передается в функцию toint:
   В функцию toint в качестве аргумента передается другая функция fun, которую требуется обернуть (декорировать).

2. Что возвращает функция toint:
   Функция toint возвращает новую функцию wrapper, являющуюся оберткой над исходной функцией fun.

3. Что делает функция wrapper:
   Функция wrapper принимает произвольное количество позиционных аргументов *args, преобразует каждый аргумент в целое число с помощью map(int, args), после чего вызывает исходную функцию fun с преобразованными целочисленными аргументами и возвращает ее результат.

#### Примеры использования функции toint

```python
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper

@toint
def add(a, b):
    return a + b

@toint
def product(a, b, c):
    return a * b * c

def hypot(x, y):
    return (x**2 + y**2) ** 0.5

calc_hypot = toint(hypot)

print(add("10", "20"))
print(product("2", "3", "4"))
print(calc_hypot("3", "4"))
```

* Пример 1: декоратор @toint для функции add(a, b). При вызове со строковыми аргументами add("10", "20") строки превращаются в числа 10 и 20, и функция выводит число 30 вместо строковой конкатенации 1020.
* Пример 2: функция умножения product("2", "3", "4") преобразует три аргумента в целые числа и возвращает 24.
* Пример 3: функция расчета длины гипотенузы hypot, обернутая через calc_hypot = toint(hypot), принимает строковые координаты "3" и "4" и возвращает число 5.0.
