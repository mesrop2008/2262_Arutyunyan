### Задание 1 **(2)**
*Рассмотрим программу на языке Python.*
```python
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if x[i] < i or x[i] > 2*i:
      break
print(i)
```
*Перепишите эту программу так, чтобы в ней использовался цикл while, в ней не использовалась инструкция break, а используемый алгоритм не изменился. Полученная программа должна иметь следующий вид.*
```python
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор not.*

#### Решение

Файл с программой: [01/main.py](01/main.py).

```python
x = [int(t) for t in input().split()]
i = 0
while i < len(x) - 1 and i <= x[i] <= 2 * i:
    i += 1
print(i)
```

В исходной программе прерывание цикла `break` происходит при выполнении условия:
```python
x[i] < i or x[i] > 2 * i
```

Для продолжения цикла `while` без инструкции `break` требуется условие, обратное условию выхода. По закону де Моргана отрицание дизъюнкции является конъюнкцией отрицаний:
$$\neg (x[i] < i \lor x[i] > 2i) \iff (x[i] \ge i \land x[i] \le 2i)$$

В языке Python цепочка сравнений записывается без оператора `not` в виде:
```python
i <= x[i] <= 2 * i
```

Также необходимо контролировать границы массива:
1. В цикле `for i in range(len(x))` переменная `i` принимает значения от `0` до `len(x) - 1`.
2. Если условие выхода ни разу не выполнилось, исходный цикл завершается, и в переменной `i` остается значение `len(x) - 1`.
3. Условие `i < len(x) - 1` останавливает инкремент переменной `i`, когда она достигает последнего индекса `len(x) - 1`, обеспечивая полное совпадение результатов работы обеих программ при любых входных данных.

### Задание 2 **(2)**
*Рассмотрим программу на языке Python.*
```python
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if i <= x[i] < 2*i or 3*i <= x[i] < 4*i:
      break
print(i)
```
*Перепишите эту программу так, чтобы в ней использовался цикл while, в ней не использовалась инструкция break, а используемый алгоритм не изменился. Полученная программа должна иметь следующий вид.*
```python
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор not.*

#### Решение

Файл с программой: [02/main.py](02/main.py).

```python
x = [int(t) for t in input().split()]
i = 0
while i < len(x) - 1 and (x[i] < i or 2 * i <= x[i] < 3 * i or x[i] >= 4 * i):
    i += 1
print(i)
```

В исходной программе условием выхода из цикла является:
```python
(i <= x[i] < 2 * i) or (3 * i <= x[i] < 4 * i)
```

Это условие означает, что $x[i]$ принадлежит объединению полуинтервалов:
$$x[i] \in [i, 2i) \cup [3i, 4i)$$

Условием продолжения цикла `while` является отрицание данного условия, то есть принадлежность дополняющим промежуткам:
$$x[i] \in (-\infty, i) \cup [2i, 3i) \cup [4i, +\infty)$$

Без использования оператора `not` это выражение записывается в виде:
```python
x[i] < i or 2 * i <= x[i] < 3 * i or x[i] >= 4 * i
```

Второй эквивалентный вариант через законы де Моргана:
```python
(x[i] < i or x[i] >= 2 * i) and (x[i] < 3 * i or x[i] >= 4 * i)
```

Условие `i < len(x) - 1` ограничивает рост индекса последним элементом массива `len(x) - 1`, сохраняя исходный алгоритм при любых входных последовательностях.

### Задание 3 **(2)**
*Напишите пример программы на Java с двумя вложенными циклами и инструкцией break для выхода из двух вложенных циклов. В качестве такой программы можно взять поиск первого нуля в двумерном массиве.*

#### Решение

Файл с программой: [03/Main.java](03/Main.java).

```java
public class Main {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 0, 6},
            {7, 8, 0}
        };

        int targetRow = -1;
        int targetCol = -1;

        search:
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[i].length; j++) {
                if (matrix[i][j] == 0) {
                    targetRow = i;
                    targetCol = j;
                    break search;
                }
            }
        }

        if (targetRow != -1) {
            System.out.println(targetRow + " " + targetCol);
        } else {
            System.out.println("not found");
        }
    }
}
```

В языке Java стандартный оператор `break` прерывает только один, непосредственно охватывающий его цикл. Для немедленного выхода из нескольких уровней вложенных циклов Java поддерживает именованный оператор `break <label>`.

Метка `search:` ставится перед внешним циклом `for`. При обнаружении первого нулевого элемента по координатам $(i, j)$ инструкция `break search;` сразу прекращает выполнение обоих циклов, передавая управление на код после внешнего цикла.

Вывод программы:
```
1 1
```

### Задание 5 **(2)**
*Напишите программу на С++, которая прочитает натуральное число n, создаст вектор из n элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу (в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора после изменения. Из циклов в программе можно использовать только циклы по коллекции.*

#### Решение

Файл с программой: [05/main.cpp](05/main.cpp).

```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<int> a(n);

    for (int &x : a) {
        std::cin >> x;
    }

    int last = a.back();
    for (int &x : a) {
        x += last;
    }

    int positive_count = 0;
    int negative_count = 0;

    for (int x : a) {
        if (x > 0) {
            positive_count++;
        } else if (x < 0) {
            negative_count++;
        }
    }

    std::cout << positive_count << " " << negative_count << std::endl;

    return 0;
}
```

В соответствии с требованием задания, в программе используются исключительно циклы по коллекции (`range-based for`):
1. `for (int &x : a)` — чтение значений элементов по неконстантной ссылке.
2. `for (int &x : a)` — добавление предварительно сохраненного последнего элемента `last = a.back()` ко всем элементам вектора.
3. `for (int x : a)` — подсчет количества положительных и отрицательных элементов.

Пример работы программы:
* Входные данные:
  ```
  5
  -10 -2 0 3 4
  ```
* Измененный вектор: $[-10+4, -2+4, 0+4, 3+4, 4+4] = [-6, 2, 4, 7, 8]$.
* Вывод:
  ```
  4 1
  ```
  (4 положительных: 2, 4, 7, 8; 1 отрицательный: -6; число 0 не является положительным или отрицательным).

### Задание 6 **(3)**
*Представим, что в некотором будущем стандарте С++ появится конструкция*
```cpp
forc(i, from, to)
```
*которая будет раскрываться в следующий код:*
```cpp
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла for? Укажите два основных различия. Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*

#### Решение

Файлы с программами: [06/diff1.cpp](06/diff1.cpp) и [06/diff2.cpp](06/diff2.cpp).

Сравнение конструкции `forc(i, from, to)` со стандартным циклом:
```cpp
for (int i = from; i < to; i++) {
    ...
}
```

#### Различие 1: Переменная цикла `i` является константной ссылкой

В конструкции `forc` переменная объявлена как `const int &i = __i`. Внутри тела цикла программист **не может изменить значение переменной `i`** (любая попытка записи `i = ...` или `i++` приведет к ошибке компиляции `assignment of read-only reference 'i'`).

В обычном цикле `for (int i = from; i < to; i++)` переменная `i` является неконстантной переменной. Ее можно модифицировать внутри тела цикла, перескакивая через элементы диапазона или изменяя шаг.

Программа [06/diff1.cpp](06/diff1.cpp):
```cpp
#include <iostream>
#include <type_traits>

int main() {
    int std_steps = 0;
    for (int i = 0; i < 5; i++) {
        if (i == 1) {
            i = 3;
        }
        std_steps++;
    }

    bool forc_is_const = false;
    int forc_steps = 0;
    {
        int __i = 0, __n = 5;
        for (const int &i = __i; i < __n; __i++) {
            forc_is_const = std::is_const_v<std::remove_reference_t<decltype(i)>>;
            forc_steps++;
        }
    }

    std::cout << std_steps << " " << forc_steps << " " << forc_is_const << std::endl;
    return 0;
}
```

Вывод программы [06/diff1.cpp](06/diff1.cpp):
```
3 5 1
```
В стандартном цикле изменение `i = 3` привело к пропуску итераций (выполнено 3 шага). В `forc` переменная `i` неизменяема (`forc_is_const = 1`), и цикл строго проходит все 5 итераций.

---

#### Различие 2: Верхняя граница диапазона вычисляется ровно один раз

В стандартном цикле `for (int i = from; i < to; i++)` выражение границы `to` вычисляется заново **на каждой итерации** при проверке условия продолжения `i < to`. Если граница является функцией или изменяемой переменной, она пересчитывается каждый раз.

В конструкции `forc` граница вычисляется **один раз** перед началом цикла при инициализации вспомогательной переменной `int __n = to;`. Изменение параметров границы во время работы цикла никак не влияет на число итераций.

Программа [06/diff2.cpp](06/diff2.cpp):
```cpp
#include <iostream>

int get_limit(int &calls) {
    calls++;
    return 3;
}

int main() {
    int calls_std = 0;
    for (int i = 0; i < get_limit(calls_std); i++) {
    }

    int calls_forc = 0;
    {
        int __i = 0, __n = get_limit(calls_forc);
        for (const int &i = __i; i < __n; __i++) {
        }
    }

    std::cout << calls_std << " " << calls_forc << std::endl;
    return 0;
}
```

Вывод программы [06/diff2.cpp](06/diff2.cpp):
```
4 1
```
В стандартном цикле функция вычисления границы вызвана 4 раза (на каждом шаге плюс финальная проверка). В конструкции `forc` функция вызвана ровно 1 раз.

### Задание 7 **(2)**
*Напишите программу на языке Python для проверки того, что все числа во введенной последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию for break else.*

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*

#### Решение

Файлы с программами: [07/main.py](07/main.py) и [07/main.cpp](07/main.cpp).

#### Программа на языке Python ([07/main.py](07/main.py))
```python
numbers = [int(x) for x in input().split()]
for x in numbers:
    if x < 0:
        print(x)
        break
else:
    print("all non-negative")
```

#### Программа на языке C++ ([07/main.cpp](07/main.cpp))
```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers;
    int x;
    while (std::cin >> x) {
        numbers.push_back(x);
    }

    bool has_negative = false;
    for (int n : numbers) {
        if (n < 0) {
            std::cout << n << std::endl;
            has_negative = true;
            break;
        }
    }

    if (!has_negative) {
        std::cout << "all non-negative" << std::endl;
    }

    return 0;
}
```

#### Изменения в алгоритме решения и их причина

1. **Появилась дополнительная переменная-флаг `bool has_negative = false`** и условная проверка `if (!has_negative)` после цикла.
2. **Причина:** В языке Python циклы `for` и `while` имеют встроенную конструкцию `else`, блок которой исполняется тогда и только тогда, когда цикл завершился естественным образом без выполнения инструкции `break`.
3. В языке C++ синтаксическая конструкция `else` для циклов отсутствует. Поэтому факт досрочного выхода из цикла программист вынужден отслеживать вручную с помощью переменной-флага состояния.

### Задание 8 **(2)**
*Рассмотрим следующую программу.*
```python
if x>=5 and y>=-5:
   print(0)
elif x<0 or y<0:
   print(1)
else:
   print(2)
```
*Опишите множества значений при которых программа выводит 0, 1 и 2. Например,*

$A=\{ (x,y)| x \in [5;\infty), y \in [-5;\infty)\}$

#### Решение

Файл с проверочной программой: [08/main.py](08/main.py).

Рассматривается плоскость вещественных чисел $\mathbb{R}^2$. Программа последовательно проверяет условия:

#### 1. Вывод 0
Ветвь `if` выполняется при одновременном выполнении условий $x \ge 5$ и $y \ge -5$:
$$A_0 = \{ (x, y) \in \mathbb{R}^2 \mid x \in [5; +\infty), y \in [-5; +\infty) \}$$

#### 2. Вывод 1
Ветвь `elif` выполняется, когда первое условие ложно, а условие `x < 0 or y < 0` истинно:
$$\neg(x \ge 5 \land y \ge -5) \land (x < 0 \lor y < 0)$$

Разбиение на непересекающиеся области:
* Если $x < 0$, то условие $x < 5$ выполняется автоматически при любых $y$: область $(-\infty; 0) \times (-\infty; +\infty)$.
* Если $0 \le x < 5$, то для истинности `elif` необходимо $y < 0$: область $[0; 5) \times (-\infty; 0)$.
* Если $x \ge 5$, то первая ветвь не срабатывает только при нарушении условия $y \ge -5$, то есть при $y < -5$: область $[5; +\infty) \times (-\infty; -5)$.

Объединение областей:
$$A_1 = \{ (x, y) \in \mathbb{R}^2 \mid (x < 0) \lor (0 \le x < 5 \land y < 0) \lor (x \ge 5 \land y < -5) \}$$

Или в виде теоретико-множественной разности:
$$A_1 = \{ (x, y) \in \mathbb{R}^2 \mid x < 0 \lor y < 0 \} \setminus A_0$$

#### 3. Вывод 2
Ветвь `else` выполняется, когда оба предыдущих условия ложны:
$$\neg(x \ge 5 \land y \ge -5) \land \neg(x < 0 \lor y < 0)$$

Условие $\neg(x < 0 \lor y < 0)$ равносильно $x \ge 0 \land y \ge 0$.
Так как $y \ge 0 \ge -5$, условие $y \ge -5$ выполняется автоматически. Тогда отрицание первой ветви $\neg(x \ge 5 \land y \ge -5)$ сводится к $x < 5$.

Область значений:
$$A_2 = \{ (x, y) \in \mathbb{R}^2 \mid x \in [0; 5), y \in [0; +\infty) \}$$

Множества $A_0, A_1, A_2$ не пересекаются и в объединении покрывают всю координатную плоскость $\mathbb{R}^2$.

### Задание 9 **(3)**
*Напишите программу на языке Python для решения следующей задачи.*

*Задана пронумерованная последовательность логических значений $t(0),t(1),..,t(n), t(i) \in \{\text{False},\text{True}\}$.*

*Последовательность обладает следующим свойством: существует некоторое число $k$ такое, что все значения $t(0),t(1),...,t(k-1)$ равны False, а все значения $t(k), ... , t(n)$ равны True, то есть слева от $k$ находятся значения False, а справа - True. Последовательность задается функцией $t(i)$, которая возвращает логическое значение. Например, для тестирования эту функцию можно задать следующим образом.*
```python
def t(i):
   return i>=1000
```
*Требуется написать программу, которая найдет число $k$. Программа должна реализовывать алгоритм бинарного поиска. Диапазон поиска задается переменными left и right. На каждом шаге вычисляется центр диапазона, значение в нем проверяется, после чего диапазон сокращается в два раза.*

*Алгоритм должен быть записан через цикл while и реализовывать инвариант цикла*
$$t(\text{left})=\text{False} \land t(\text{right})=\text{True}$$

```python
left = -1
right = 10**18
while ...:
   mid = ...
   if t(mid):
      ...
   else:
      ...
print(...)
```

#### Решение

Файл с программой: [09/main.py](09/main.py).

```python
def t(i):
    return i >= 1000

left = -1
right = 10**18

while right - left > 1:
    mid = (left + right) // 2
    if t(mid):
        right = mid
    else:
        left = mid

print(right)
```

#### Обоснование алгоритма и инварианта цикла

1. **Начальное состояние:**
   - При $i < 0$ функция возвращает $\text{False}$, поэтому $t(\text{left}) = t(-1) = \text{False}$.
   - При $\text{right} = 10^{18}$ гарантируется $t(\text{right}) = \text{True}$.
   - Инвариант $t(\text{left}) = \text{False} \land t(\text{right}) = \text{True}$ выполнен перед входом в цикл.
2. **Шаг цикла:**
   - Вычисляется середина диапазона $\text{mid} = (\text{left} + \text{right}) // 2$.
   - Если $t(\text{mid}) == \text{True}$, то первое истинное значение находится в точке $\text{mid}$ или левее нее. Присваивание $\text{right} = \text{mid}$ сужает правую границу и сохраняет инвариант $t(\text{right}) = \text{True}$.
   - Если $t(\text{mid}) == \text{False}$, то все элементы до $\text{mid}$ включительно равны $\text{False}$. Присваивание $\text{left} = \text{mid}$ сужает левую границу и сохраняет инвариант $t(\text{left}) = \text{False}$.
3. **Условие завершения:**
   - Цикл продолжается, пока $\text{right} - \text{left} > 1$.
   - При завершении цикла $\text{right} - \text{left} == 1$, то есть $\text{left}$ и $\text{right}$ становятся соседними индексами.
   - В силу инварианта $t(\text{left}) = \text{False}$ и $t(\text{right}) = \text{True}$.
   - Следовательно, наименьшим индексом, для которого значение истинно, является в точности **`right`**, равный искомому числу $k$.
